# Locally hosted preprint PDFs

The public [Preprints](../preprints.html) page includes arXiv links and working manuscripts in one reverse-chronological list.

Upload replacement PDFs here using stable filenames and update their corresponding citation in `preprints.html`, preserving the original arXiv submission date where applicable. Local manuscript upload/revision dates are explicitly distinguished from arXiv dates.

Older `ai-papers/` URLs remain available as legacy links for existing readers, but the separate AI-Aided Papers navigation section has been retired and its old page redirects to Preprints.
